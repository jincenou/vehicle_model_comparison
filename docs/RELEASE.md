# Release scope and limitations

This export was assembled independently of the active experiment workspace. It contains selected project-authored scripts, numerical code, small metadata projections and documentation. Original numerical modules were copied byte-for-byte; literal deployment roots in workflow scripts were parameterized and comments sanitized. `provenance/source_files.json` records original/published SHA-256 pairs.

Included: real input staging, native generation/reload, representative scene workflows, orientation/camera contracts, metric primitives, tests, and frozen public membership metadata.

Excluded: dataset payloads, retained crops/masks, native assets, weights, environment caches, logs, per-process state, private source mappings, screening galleries, obsolete score tables, failed iteration outputs, and the cancelled static/non-vehicle extraction repair branch. No third-party source checkout is vendored.

The original scene split contents, complete pipeline asset provenance, legacy TRELLIS loader and all upstream local patches are not included. These are concrete gaps in clean-machine replay. Snapshot helper imports may retain historical multi-purpose names, but this release's cohort and documented scope are rigid assets only. A research snapshot is not a validated turnkey package.

The repository intentionally contains no final leaderboard, paper metadata or fabricated performance numbers. No self-contained recreation of the `ours` asset-generation pipeline is claimed. Owner-authored code licensing remains to be selected; upstream licenses cannot be replaced by this repository.

The snapshot's dated paths are lineage identifiers. They are not instructions to write into an existing deployment. New runs need isolated writable output/state directories and explicitly resolved inputs.
